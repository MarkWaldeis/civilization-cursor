# Civilization Cursor

2D-Hexwelt im Stil von Civilization 6 — prozedural generierte Landschaft, Küsten, Gebirge, Dschungel und Flüsse mit Sandufern, Mäandern, Quellen und Mündungen.

## Direkt testen

**https://markwaldeis.github.io/civilization-cursor/**

Die Karte läuft komplett im Browser (eine HTML-Datei, keine Installation).

## Steuerung

- **Ziehen** — Karte bewegen
- **Mausrad** — Zoomen
- **Klick auf zwei begehbare Felder** — Weg prüfen

## Projektstruktur

| Pfad | Inhalt |
|------|--------|
| `civilization-map.html` | Komplette Anwendung (Karte, Generator, Renderer) |
| `index.html` | Einstieg für GitHub Pages |
| `referenz/` | Tile-Referenzgrafiken und Manifest |
| `assets/rivers/` | Fluss-Referenz-PNGs (Palette & Stil) |

## Entwicklung lokal

`civilization-map.html` im Browser öffnen — fertig.
